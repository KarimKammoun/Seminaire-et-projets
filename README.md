# TP : reconnaissance d'émotions

Ce dépôt contient l'énoncé, les données du TP et une solution expliquée. Auteur du rapport : Karim Kammoun.

- `TP/TP-EMotions.docx` : énoncé original.
- `TP/*.mat` : données originales (séquences, labels et sujets).
- `TP/CorrectionHassen18_10_2021.py` et `TP/FramePreshapeAligned.png` : code et illustration fournis initialement.
- `TP/livrable/tp_emotions.py` : programme complet ; `procrustes_prof.py` : fonction fournie par le professeur.
- `TP/livrable/rapport.pdf` et `rapport.md` : explications et résultats.
- `TP/livrable/resultats/` : résultats de l'expérience.
- `TP/livrable/LISEZ_MOI.md` : installation et commandes détaillées.

Pour exécuter le programme, conserve l'organisation des dossiers : les fichiers `.mat` restent dans `TP`, juste au-dessus de `TP/livrable`.
